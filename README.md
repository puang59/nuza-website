# nuza-web 
source code for the nuza landing page, built with astro and tailwind.

[<img src="public/intro-preview.png" alt="Watch the nuza intro video" width="100%" />](https://nuza-cdn.puang.in/nuza-intro-v3.mp4)

commands:
- `bun install` to install dependencies
- `bun dev` to start dev server
- `bun build` to build for production
